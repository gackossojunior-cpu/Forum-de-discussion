━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ PUBLIER UNE QUESTION
  1. Cliquer "Publier une question"
  2. Sélectionner une catégorie (ex: "Technique")
  3. Titre: "Comment faire une boucle en PHP?"
  4. Description: "Je voudrais apprendre les boucles"
  5. Cliquer "Publier la question"

✅ VOIR LA QUESTION
  1. Retour à la page principale
  2. La question apparait en haut
  3. Badge "Technique" visible
  4. Boutons 👍 et 👎 pour voter

✅ VOTER
  1. Cliquer 👍 (ou 👎)
  2. Le compteur augmente
  3. Cliquer à nouveau pour annuler

✅ RÉPONDRE
  1. Cliquer "Voir la question"
  2. Remplir "Votre réponse"
  3. Cliquer "Publier la réponse"
  4. Réponse visible avec ses votes 👍👎

✅ SIGNALER
  1. Sur une question/réponse, cliquer 🚩
  2. Modal apparait
  3. Choisir raison (ex: "Spam")
  4. Ajouter description (optionnel)
  5. Cliquer "Signaler"

✅ FILTRER
  1. Sélectionner catégorie: "Général"
  2. Cliquer "Rechercher"
  3. Seules les questions de "Général" s'affichent

✅ RECHERCHER
  1. Taper dans le champ de recherche
  2. Cliquer "Rechercher"
  3. Résultats filtrés par titre/contenu
  4. Combinaison possible avec catégorie

✅ VOIR LES NOTIFICATIONS
  1. Cliquer "📬 Notifications" (dans la navbar)
  2. Page dédiée aux notifications
  3. Espace réservé pour messages du système

Pour devenir admin:

1. Ouvrir phpMyAdmin: http://localhost/phpmyadmin
2. Base "forum" → Table "users"
3. Éditer votre utilisateur
4. Changer "role" de "user" à "admin"
5. Retour au forum

Vous verrez maintenant:
  - Lien "🔐 Admin" dans la navbar

URL Admin: http://localhost/forum/admin/dashboard.php

Dashboard affiche:
  - Nombre d'utilisateurs
  - Nombre de questions
  - Nombre de réponses
  - Signalements en attente ⚠️

Gestion des signalements:
  1. Cliquer sur un signalement
  2. Voir le contenu signalé
  3. Boutons:
     - "Accepter et Supprimer": Supprime le contenu offensant
     - "Refuser": Rejette le signalement

❌ Erreur "could not find driver"
   → MySQL n'est pas lancé
   → Vérifiez que MySQL est RUNNING dans XAMPP

❌ Erreur 404
   → Les fichiers ne sont pas dans C:\xampp\htdocs\forum\
   → Vérifiez l'emplacement

❌ Erreur "Base de données"
   → Relancez http://localhost/forum/setup.php

❌ Admin panel inaccessible
   → Vérifiez que votre rôle = "admin" dans phpMyAdmin
   → Reconnectez-vous
